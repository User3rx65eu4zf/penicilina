## Architecture
- Inventory business rules live as pure functions in `src/lib/inv/logic.ts`; UI calls them through `run()` in `src/lib/inv/store.ts` (transactional, persisted in localStorage) so the storage layer can be swapped for a backend without touching rules.
- Demo data in `src/lib/inv/seed.ts` is generated by executing the real actions, so Kardex balances always match stock; keep seeding through actions, never hand-written rows.
