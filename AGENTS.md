## Architecture
- Inventory business rules remain in `src/lib/inv/logic.ts`; UI awaits `run()` in the shared Cloud repository, which rebases mutations with optimistic version checks and atomically records successful operations to prevent lost updates.
- Demo data in `src/lib/inv/seed.ts` is generated by executing the real actions, so Kardex balances always match stock; keep seeding through actions, never hand-written rows.
- Keep simulated actor selection local to each device; never treat it as authentication or security authorization, and never overwrite shared state when a new browser connects.
- Dashboard product metrics derive from committed inventory and operation logs; engineering metrics stay unmeasured until an actual CI data source exists.
